# Provider transport contracts

Reviewed 2026-10-09. Offline contract tests exercise request shapes and SDK call signatures. They are not evidence of account access, device availability, or successful hardware execution. Credentials are supplied through the resolved adapter config or each SDK's standard credential store. No adapter mutates process environment variables, invokes a circuit transpiler, or automatically retries a submission.

QIR uses an explicit target `qir_platform`: `standard`, `quantinuum-h2`, or `quantinuum-helios`. Quantinuum's native `rxy(theta, phi, qubit)` and runtime `__quantum__rt__read_result` are documented extensions; standard QIR uses `__quantum__qis__read_result__body`. Initialization is emitted for standard/Helios and omitted for H2. Classical assignments and nested branches use SSA values and `phi` joins, preserving overwritten predicates and unassigned zero bits without unsupported stack memory. Output has unique non-null labels, and irreversible measurement/reset declarations carry their required attribute. The base profile rejects unmeasured classical output slots and quantum transformations after irreversible operations. Felis remains restricted to static circuits and the QIS signatures advertised by its selected target; unsupported control flow or Quantinuum QIR is rejected before job creation. These checks establish serialization contracts, not live provider acceptance. Sources: [Quantinuum QIR](https://docs.quantinuum.com/nexus/trainings/notebooks/basics/qir/index.html), [QIR 1.0 base](https://github.com/qir-alliance/qir-spec/blob/1.0/specification/profiles/Base_Profile.md), [QIR 1.0 adaptive](https://github.com/qir-alliance/qir-spec/blob/1.0/specification/profiles/Adaptive_Profile.md), [Felis instructions](https://felis.alice-bob.com/docs/reference/supported_instructions/).

QCI means **Quantum Circuits Inc Aqumen**, not Quantum Computing Inc; its raw API is not publicly verified. TII Falcon has no verified cloud contract. These two routes report unavailable. Qibolab requires the explicit laboratory bridge described above.

AQT's optional `credentials_file` is the exact TOML file to read, using the connector's `[default]` configuration fields. Because pinned connector 0.4 normally accepts only a directory and a fixed `config` filename, the adapter supplies the parsed file through its configuration loader hook. It neither copies credentials nor reads a sibling config file; the file's parent directory remains the connector token-cache directory. Environment and explicit resolved options keep their normal precedence.

IQM discovery restricts normalized routing to computational qubits and direct native loci. Architectures that require MOVE through reserved resonator slots remain unverified until the owned compiler implements that routing model. A device with direct computational-qubit CZ loci remains usable even if it also has resonators. OQC SDK 3.23.0 supports Python 3.12 only; its extra is environment-marked, and other Python versions receive an explicit dependency error before client creation.

Azure discovery combines actual account target availability with exact, dated official contracts for H2-1/H2-2 and IonQ Aria/Forte. Unknown Azure targets remain unverified. General H2 emulator capacity is conservatively 32 qubits; syntax checkers are labelled and do not establish hardware execution. Azure Quantinuum disables documented optimization switches. Azure's QIR entryPoint matches the artifact's qir_entry_point (default main); mismatched configuration is rejected before submission. Direct and Azure IonQ disable default debiasing, which can otherwise change mappings and decompositions.

Quantinuum QASM2 export uses its HQSLIB dialect: `U1q(theta,phi)`, `Rz(angle)`, and `RZZ(angle)` retain radians and physical indices. A single `c` register preserves sparse readout destinations. Simple conditions use the documented `if(c[n]==value)` extension; nested branches, conditional barriers, and writes to a branch's predicate are rejected because flattening them would change semantics. Global and branch-local scalar phase remain in the physical artifact with comments in this sampling-only export. The offline oracle uses Quantinuum's actual parser; generic QASM2 parsers can reject these valid dialect extensions. No pytket rebase or compilation runs in the exporter. [HQSLIB declarations](https://github.com/Quantinuum/tket/blob/main/pytket/pytket/qasm/includes/hqslib1.inc), [Quantinuum parser and conditional export](https://docs.quantinuum.com/tket/api-docs/_modules/pytket/qasm/qasm.html).

OQC discovery initially produces unverified records containing the exact QPU ID, raw calibration, and `calibration_sha256`. To enable an account with an authoritative hardware contract, configure both `device` and `capability_snapshot` (a JSON file). Its fields are `schema_version: 1`, `route: "oqc"`, the exact `device`, `attestation: "account-provided"`, nonempty `capability_sources`, and the current `calibration_sha256`; it must also supply positive `qubits`, explicit `native_gates`, physical `coupling` pairs, boolean `all_to_all`/`directed_connectivity`, `parameter_units: "radians"`, accepted `formats`, and all three boolean `supports` fields (`reset`, `mid_circuit_measure`, `feedforward`). Optional gate loci, qubit labels and supplied numerical calibration data are retained. Discovery checks that the QPU is still active and that the calibration hash matches. This is an operator attestation, labelled `capability_verification: "account-provided-calibration-bound"`, rather than independently verified hardware capability. No topology is inferred from opaque benchmarking data. Refresh the account contract when calibration changes.

IBM numerical errors and durations come directly from `Target` instruction properties; seconds are converted to nanoseconds. QCS errors use the official ISA fidelity characteristics (`fCZ`, `fISWAP`, `fCPHASE`, `fXY`, `fRO`) and one-qubit randomized benchmarking data; characteristic uncertainty is not operation error. Multiple operation errors at a locus are conservatively summarized by their maximum. Missing values remain absent. QCS durations remain absent because the public ISA contract does not establish timing units, and pyQuil default timing guesses are not calibration. [Qiskit Target](https://quantum.cloud.ibm.com/docs/en/api/qiskit/qiskit.transpiler.Target), [QCS fidelity normalization](https://github.com/rigetti/pyquil/blob/master/pyquil/quantum_processor/transformers/qcs_isa_to_compiler_isa.py).

Immediately before IBM submission, the actual current `Target.instruction_supported` contract verifies ordered physical operands and parameter bounds for every operation, including gates inside conditional regions. Symmetric gate matrices do not imply that a backend accepts both operand orders. Control-flow availability is checked separately; this guard never transforms the circuit.

IonQ estimates use authenticated v0.4 `GET /jobs/estimate` with counts from the exact native artifact; only a response explicitly denominated in USD can satisfy a dollar cap. AWS estimates query the Braket SDK's current public AWS Price List for both the regional QPU task fee and shot fee; missing, ambiguous or non-USD prices fail closed. These are preflight estimates, not a provider billing guarantee, and the AWS amount excludes ancillary services and taxes. No fixed registry rate is substituted. Other providers have no verified pre-execution USD contract here; an unknown estimate cannot satisfy a USD cap. [IonQ estimate](https://docs.ionq.com/api-reference/v0.4/jobs/get-job-estimate), [Braket price lookup](https://github.com/amazon-braket/amazon-braket-sdk-python/blob/main/src/braket/tracking/pricing.py), [Braket task-cost formula](https://github.com/amazon-braket/amazon-braket-sdk-python/blob/main/src/braket/tracking/tracker.py).

Nexus and QCS custom SDK configuration files are read in isolated child processes with documented environment overrides. Credential values travel through stdin rather than process arguments; the parent environment is unchanged and timed-out writes are never automatically retried.

Results retain native register ordering and metadata. A `counts` field is populated only from actual integer shot histograms, never by rounding probabilities. Capability discovery records without a complete normalized compiler contract set `capability_verified: false`; a successful discovery request is not permission to infer missing gates or connectivity.
